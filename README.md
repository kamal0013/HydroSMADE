# Exploring HydroSMADE Dataset

This repository contains example Jupyter Notebooks to explore the **HydroSMADE (Hydropower Site-level Monthly Availability Data Ensemble)** v1.0 dataset, publicly available on MSD LIVE at [this link](https://doi.org/10.57931/3015845).

HydroSMADE is a new open dataset that provides monthly hydropower availability for 1,593 existing and 124,333 potential sites worldwide over the period 1950–2100. The dataset is generated by using a global hydrologic model (Xanthos) with explicit representation of hydropower operation. Specifically, HydroSMADE distinguishes between storage and diversion sites, applies optimized operating rules, and incorporates site-specific characteristics such as generation capacity, maximum turbine flow, and reservoir storage. Driven by bias-corrected meteorological inputs, the data is provided for 30 alternative future scenarios. 


## Available Notebooks

- **plot_annual_hydro_by_basins.ipynb** — reads site-level monthly hydropower availability data for a river basin of interest, and then estimates and plots basin-level trajectory of annual hydropower availability.
- **plot_monthly_mean_hydro_by_basins.ipynb** — reads site-level monthly hydropower availability data for a river basin of interest, and then estimates and plots basin-level monthly mean hydropower availability.


## Dataset Organization

The repository contains a total of 122 files: a text file (readme.txt) containing a brief description of the included data, a CSV file containing site attributes, and the remaining 120 files (in CSV) containing site-level monthly hydropower availability.


## Quick Start

1. Download the HydroSMADE data from [MSD LIVE](https://doi.org/10.57931/3015845).
2. Open a notebook.
3. Define the basin of interest.
4. Run the cells to read HydroSMADE data, estimate the basin-level annual/monthly hydropower availability for each scenario.
5. Plot the estimated data, separately for diversion- and storage-type sites.
6. Edit and rerun cells as needed.
